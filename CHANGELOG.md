# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-05-27

### Added

- A central `VERSION` file and sync tooling to keep release metadata aligned.
- A GitHub Actions release workflow that validates the package and publishes a GitHub release from the central version.

### Changed

- Declared the current HTML-to-RTF feature set as the stable `1.0.0` release.
- Updated the README badge to track GitHub releases instead of the npm package version.
